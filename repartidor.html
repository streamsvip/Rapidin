Conviértete en Repartidor Rapidín

Genera ingresos realizando entregas en Camaná mediante un sistema inteligente donde tú decides qué pedidos aceptar y qué ofertas enviar a cada cliente.

📦 Catálogo Referencial

Tendrás acceso a una cartilla de precios referenciales de comidas, bebidas, medicamentos, minimarkets y otros productos disponibles en Camaná para ayudarte a calcular tus ofertas.

💰 Tú defines el precio

Cada repartidor puede establecer el valor de sus servicios considerando distancia, tiempo, tráfico, disponibilidad y complejidad del pedido.

🚀 Activación Inicial

Para comenzar se realiza un único pago de activación de S/50. Como beneficio de bienvenida recibirás S/20 de saldo operativo en tu cuenta.

📲 Saldo Operativo

Por cada pedido completado se descontará S/1.50 de tu saldo. Mientras tengas saldo disponible podrás enviar ofertas y aceptar pedidos.

🏦 Recargas

Podrás recargar saldo mediante Yape, Plin, Lemon o transferencia bancaria directamente desde tu panel.

💵 Cobro Directo

El cliente realiza el pago directamente al repartidor mediante Yape, Plin o Lemon al finalizar la entrega.

Políticas y Condiciones

Rapidín proporciona precios referenciales para ayudar a los repartidores a elaborar propuestas competitivas. Cada repartidor conserva total libertad para definir sus ofertas.

En caso de pérdida, error o inconveniente con un producto adquirido, el cliente dispondrá de un máximo de una hora para reportar el incidente.

Para evaluar cualquier solicitud será obligatorio presentar comprobante o boleta de compra correspondiente.

Los repartidores representan la imagen de Rapidín frente a cada cliente, por lo que se espera responsabilidad, puntualidad y una atención profesional.
