¿Cómo funciona Rapidín?

Un sistema inteligente de pedidos con ofertas de repartidores

Sistema tipo marketplace de delivery

1. El cliente crea el pedido

El usuario publica lo que necesita: comida, productos, compras o medicamentos. El pedido se guarda como una solicitud abierta.

2. Los repartidores ven la solicitud

Todos los repartidores activos pueden ver el pedido publicado y decidir si quieren participar.

3. Cada repartidor envía una oferta

No hay precio fijo. Cada repartidor propone su propio precio incluyendo producto + envío + tiempo estimado.

4. El cliente compara y elige

El cliente recibe varias ofertas y elige la mejor según precio, tiempo o confianza. Aquí está el poder del sistema.

5. Se asigna el repartidor ganador

Al aceptar una oferta, el pedido queda bloqueado y el repartidor seleccionado se encarga de la entrega.

6. Seguimiento en tiempo real

El cliente puede ver el estado del pedido: en preparación, en camino y entregado.

🔄 Flujo del sistema:

Cliente crea pedido → Se publica → Repartidores envían ofertas → Cliente elige → Se asigna repartidor → Compra/recoge → Entrega → Tracking final
